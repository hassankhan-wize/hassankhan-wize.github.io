# Hassan Khan — Freelancer Portfolio

A clean, single-page portfolio for Hassan Khan, an independent full-stack engineer building production-ready SaaS products, web applications, APIs, automations, and Flutter companions.

The site is dependency-free and deploys directly to GitHub Pages. It uses the existing portfolio screenshots and profile data while presenting the work anonymously, without past-company history.

## Run locally

Open `index.html` in a browser, or serve the folder locally:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy to GitHub Pages

1. Create a GitHub repository and push this folder to the `main` branch.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, then select `main` and `/ (root)`.

The site has no build step. Update the copy in `index.html`, styling in `css/style.css`, and interactions in `js/main.js`.
